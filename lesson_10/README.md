Как запустить тесты для формирования отчёта Allure
Перед запуском убедиться, что:
Шаг 1
1. Вы находитесь в папке lesson_10 (где лежат тесты и файлы страниц);
2. Виртуальное окружение активировано
3. Все зависимости установлены (pip install -r requirements.txt выполнен).
Шаг 2
1. Запустите тесты с генерацией данных для отчёта (pytest --alluredir=allure-results)
2. После выполнения команды: тесты будут запущены и выполнены; в папке проекта появится директория allure-results/ — в ней хранятся JSON‑файлы с данными для отчёта.
3. Сгенерируйте и запустите отчёт: (allure serve allure-results)
   Отчёт откроется в браузере
